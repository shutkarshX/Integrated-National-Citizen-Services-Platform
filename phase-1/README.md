# Integrated National Citizen Services Platform — Phase 1

**Course:** Operating Systems (CCSE0303A)  
**Group:** 66  
**Scope:** Official syllabus Modules 1 and 2

This directory is the fresh implementation workspace. The existing implementation at the repository root is retained as-is and is not part of this new workspace.

## Phase 1 objectives

- Demonstrate Linux operating-system fundamentals through real Linux command-line inspection and documented observations.
- Use Bash scripts to automate repeatable system and project tasks.
- Model citizen-service requests as application-level processes.
- Demonstrate process lifecycle and CPU scheduling concepts with an inspectable implementation.
- Study and document threads and multithreading accurately; do not describe a sequential simulation as concurrent execution.

## Planned structure

- `src/` — new application source code.
- `scripts/` — Linux/Bash automation.
- `tests/` — automated tests.
- `docs/` — design notes, syllabus mapping and evidence records.

## Environment

The implementation is intended to be developed and demonstrated on Linux. Python and Bash may be used where they directly support the OS learning objectives.

## Evidence policy

Only mark a feature complete after it has been implemented and tested. Capture screenshots from the actual Linux terminal or running application. Do not fabricate command output, screenshots, test results, or report claims.
